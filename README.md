# Personal Portfolio

## Overview

This is my personal portfolio, created to showcase my skills, projects, and experience. The portfolio was developed using Next.js, Framer Motion for animations, Shadcn UI for the design elements, and React Icons. This project was guided project and made it while learning next js.

## Technologies Used

- **Next.js**: Framework for building the frontend.
- **Framer Motion**: Used for creating animations and transitions.
- **Shadcn UI**: Used for UI components and styling.
- **React Icons**: Used for adding icons to the UI.

## Features

- Home page with an introduction and brief overview.
- About page detailing my skills and experience.
- Projects page showcasing my work.
- Contact page with a form to get in touch.
